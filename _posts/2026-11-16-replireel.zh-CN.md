RepliReel 是我做的一个 AI 带货视频生成工具。看中一条卖得好的短视频广告，把它和一张你的产品图一起传上去，RepliReel 会照着原片的剧情、节奏和台词结构，换成你的产品重新拍一条新广告。

做 [VideoLens](https://videolens.cc/zh) 的时候，很多用户拆完一条爆款，下一句就问：「能不能直接帮我拍一条一样的？」RepliReel 就是这个问题的答案——VideoLens 负责「拆」，RepliReel 负责「拆完照着拍」。

> 💡 访问地址：<https://replireel.com/zh>
{: .prompt-tip }

## 一个真实例子

原片卖的是一件米白色加绒纽扣马甲，剧情是熟人在街头偶遇，一句「才三十多块不冷吗」的反问把价格抛出来。我换成了一件深灰色立领拉链马甲：

![RepliReel 成片截图](https://replireel.com/showcase/vest/final.jpg){: w="360" }
_换品后的成片：人物、场景、台词都重新生成，结构和节奏沿用原片_

| 改了什么 | 原片 → 新广告 |
| --- | --- |
| 人物 | 姨姨 + 年轻男子 → 年轻宝妈 + 闺蜜 |
| 产品动作 | 扣纽扣、翻领特写 → 拉拉链、立领、斜插口袋特写 |
| 台词 | 保留「才三十多块不冷吗」的反问钩子，卖点换成立领防风、加厚内胆 |
| 节奏 | 沿用原片 3 段结构和每段时长 |

原片和成片的完整对照视频在 [样例页](https://replireel.com/zh/showcase)。

## 它是怎么做的

上传之后，RepliReel 会一步步往下走：

1. **拆解原片**——分段、镜头、人物、场景、台词、卖点和开头钩子
2. **改编成你的产品**——保留原片的结构和每段时长，产品、人物、场景、台词换成你的
3. **出参考图**——角色、场景、道具各画一张，保证每段画面里的人和东西是同一个；角色是按方案新设计的人物，不照搬原片里真人的长相
4. **生成视频片段**——每段最长 15 秒，多段并行生成
5. **拼接成片**——在线播放、直接下载

## 两种模式

| 模式 | 适合 | 怎么用 |
| --- | --- | --- |
| **自定义**（默认） | 想按自己的产品调整剧情 | 先出几个改编方向供你挑，选中后再出详细方案；方案出来先停下，每段的画面、台词、时长都能改；参考图逐张确认，不满意改描述重画 |
| **全自动** | 想快速出片、原片剧情直接能用 | 照原片剧情直接复刻，上传后直接出成片，不用守着 |

生成过的成片、角色图、场景图都会存进「我的作品」，下一个项目可以直接选用，不用再画一遍。成片做完还可以「换个方向，再做一条」，复用原片拆解，直接出另一个版本。

## 适合谁用

| 人群 | 用法 |
| --- | --- |
| **抖音 / 小红书 / 淘宝商家** | 不找拍摄团队，用同行跑出来的爆款结构给自己的产品出广告素材 |
| **投放 / 运营** | 同一个验证过的广告结构，快速换不同产品做 A/B 测试 |
| **代运营 / 广告公司** | 批量产出商品短视频，先出初稿再人工精修 |
| **TikTok 跨境卖家** | 把国内跑通的广告结构，换成自己的产品再拍一版 |

## 使用方式

1. 打开 [replireel.com/zh](https://replireel.com/zh)，用 Google 或邮箱登录（不用密码）
2. 上传参考广告：本地视频，或直接粘贴抖音 / 小红书 / TikTok 链接（最长 60 秒）
3. 上传一张产品图，选自定义或全自动
4. 拆解和改编几分钟就好，视频每段约 5–10 分钟，全自动模式下做完了去「我的项目」里看

按用量计费，每一步成功才扣，生成失败自动退回，具体价格以 [价格页](https://replireel.com/zh/pricing) 为准。
